SeBa population runs

Run a population of binaries with SeBa in your browser and download the data file. The initial masses, mass ratios, separations and eccentricities are drawn at random from the distributions you choose below (SeBa option -R).

The output is the usual SeBa.data file: one line per moment in the evolution of a binary when something changes. See the SeBa README for the meaning of the columns.

Everything is computed on your own computer, so large runs can take a while. Keep this tab open and in front, and don't let your computer go to sleep. To combine several runs into one population, give each run a different first ID and a different random seed, then put the files after each other.
